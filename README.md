# MAP-TECH Admin Dashboard

A comprehensive admin dashboard for managing MAP-TECH 2K26 event registrations with Firebase integration.

## Features

### 🗑️ Delete Functionality (New!)
- Delete registrations directly from the UI
- Confirmation dialog to prevent accidental deletions
- Real-time updates after deletion
- Proper error handling and user feedback

### 📊 Advanced Excel Export
- Multiple worksheets (All Registrations + Event-specific + Summary)
- Professional styling with colors and formatting
- Auto-filters and auto-sized columns
- Summary statistics and analytics

### 📄 Professional PDF Export
- Beautiful cover page with branding
- Summary statistics page
- Event-based organization
- Styled registration cards
- Multi-page support with headers/footers

### 🔍 Search & Filter
- Real-time search by name
- Filter by event type
- Responsive and fast

### 📱 Responsive Design
- Works on desktop, tablet, and mobile
- Smooth animations and transitions
- Professional UI with MAP-TECH branding

## Technologies

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Database**: Firebase Firestore
- **Libraries**: 
  - Firebase SDK 12.8.0
  - XLSX 0.20.3 (Excel export)
  - jsPDF 2.5.2 (PDF generation)
  - Font Awesome 6.7.2 (Icons)

## Getting Started

1. Clone the repository
2. Open `index.html` in a modern browser
3. Ensure Firebase configuration is set up correctly
4. Configure Firebase security rules for delete permissions
